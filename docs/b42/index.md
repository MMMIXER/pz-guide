# Build 42 核心变化总览

Build 42（Unstable）是僵尸毁灭工程有史以来**最大的更新**，开发历时三年。核心理念：从文明废墟中劫掠的幸存者，转变为**自给自足的后末日重建者**。

本文面向 B41 老玩家，只讲**变了什么**，基础机制不重复。

---

## 十大核心变化速览

| #   | 变化          | B41 情况   | B42 情况                        | 影响        |
| --- | ------------- | ---------- | ------------------------------- | ----------- |
| 1   | **锻造系统**  | 无         | 可冶炼铁矿、锻打刀剑、自制钉子  | 🔴 全新     |
| 2   | **动物/畜牧** | 无活物     | 8 种动物，可驯养狩猎            | 🔴 全新     |

| 4   | **肌肉疲劳**  | 无限挥砍   | 重武器造成肌肉拉伤，需轮换      | ⚠ 影响战斗  |
| 5   | **地下空间**  | 无         | 地下室、避难所、地堡            | 🔴 全新     |
| 6   | **高楼大厦**  | 最高 7 层  | 最高 32 层摩天楼                | ⚠ 影响探索  |

## 对 B41 老玩家的核心提示

### 你必须改的习惯

- **拆家具不给木工 XP 了** — 想练木工必须造东西，不是拆东西
- **技能书不只是 XP 倍率** — 很多配方**必须读了书才能解锁**
- **不能无脑抡重武器** — 肌肉疲劳系统让轻型武器有了存在意义
- **手电筒必带** — 室内和夜晚现在是真的黑，不是以前那种灰色暗
- **武士刀是消耗品了** — B42 不能磨武士刀，坏了就没了

### 可以继续用的经验

- 丧尸基础 AI 没变（依然是视/听觉驱动）
- 水电断供机制没变
- 车辆系统基本没变
- 基础生存机制（饥饿/口渴/体温/伤口）框架没变
- Life and Living 电视节目仍存在，但开局职业起点更高，没那么依赖 TV

## B42 更新时间线

B42 于 **2024 年 12 月** 上线 Steam Unstable 分支，至今仍在持续更新：

| 版本     | 日期    | 关键内容                                                   |
| -------- | ------- | ---------------------------------------------------------- |
| B42.0.0  | 2024.12 | 初始 Unstable：锻造、动物、地下室、光照、高楼、农业2.0     |
| B42.14.0 | 2026.02 | 大量平衡性调整，修复 250+ bug                              |
| B42.16.0 | 2026.03 | 职业重做、新特征 Tinkerer/Target Shooter、枪支配件 3D 模型 |
| B42.17.0 | 2026.04 | 新城镇、职业微调、多人模式修复                             |

**预计稳定版**：目标 2025（已推迟，Unstable 仍在完善中）

**多人模式**：Unstable 初期被禁用，B42.17 开始重新启用

**存档兼容**：B41 存档 ==不兼容== B42，需开新档
