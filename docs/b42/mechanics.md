# 新机制详解

B42 引入了大量影响日常玩法的系统级变化。本章汇总核心的新机制，每个都对 B41 玩家的习惯构成挑战。

---

## 💡 光照重做——真正的黑暗

B42 用全新的**光线传播系统**取代了 B41 的方块式房间亮度模型。

### B41 vs B42

| 方面       | B41                | B42                          |
| ---------- | ------------------ | ---------------------------- |
| 光照模型   | 基于房间的方块亮度 | 光线在墙体间反弹、从门窗漏出 |
| 夜晚室内   | 灰暗但可见         | **完全漆黑**                 |
| 手电筒     | 可有可无           | **必需品**                   |
| 光源可见性 | 不影响丧尸警觉     | 丧尸从更远处看到光           |

### 实战影响

- 没有手电或火源进地下室 = 自杀
- 发电机和电池的价值大幅上升
- 蜡烛成为重要的应急光源
- 霓虹灯、路灯、火光都有真实的光影投射
- 夜晚感觉像真正的夜晚——"令人不适的黑暗"
- 墙上的开关会发出微弱光晕，可以利用它定位

::: tip 适应建议
身上永远带手电 + 备用电池。进入任何未知建筑前先开灯。把发电机和燃料的优先级提上去。
:::

## 💪 肌肉疲劳系统 (Muscle Strain)

B42 最影响战斗的新机制——**重武器会造成肌肉拉伤**。

### 机制说明

- 每次挥舞武器都会累积**肌肉疲劳**
- 武器越重（Encumbrance 越高），疲劳积累越快
- 疲劳过高 → 伤害降低 → 挥速变慢 → 更危险
- 需要**休息**或**换轻型武器**来恢复

### 武器重量与疲劳

| 武器类型                     | 重量等级 | 可持续战斗时间 |
| ---------------------------- | -------- | -------------- |
| 短刀 (Hunting Knife)         | 极轻     | 极长           |
| 短棍 (Nightstick, Hammer)    | 轻       | 长             |
| 手斧 (Hand Axe)              | 中       | 中等           |
| 长棍 (Crowbar, Baseball Bat) | 中重     | 中等偏短       |
| 双手斧 (Fire Axe, Wood Axe)  | 重       | 短             |
| 大锤 (Sledgehammer)          | 极重     | 极短           |

### 适应策略

1. **武器轮换**：不要一把武器砍到底，准备两把不同类型的武器
2. **轻型武器有价值了**：B41 时代无人问津的小刀和短棍现在有了真正的用武之地
3. **战斗节奏变慢**：莽撞行为受到惩罚，更注重战术
4. **维护技能更重要**：保养好的武器效率更高，能用更少挥砍解决问题

## 🎣 钓鱼重做

B42 的钓鱼从"对着水面点菜单"变成了**观察+互动**的迷你游戏。

### 变化

| B41           | B42                                     |
| ------------- | --------------------------------------- |
| 右键水面 → 等 | 先观察水面找鱼群                        |
| 固定收鱼率    | 鱼群位置和密度每局随机                  |
| 无视觉反馈    | 水面有**可见鱼花**（鱼跃水面的 splash） |
| 无环境影响    | 枪声会**吓跑鱼**，暂时停止咬钩          |

### 新机制

- **鱼饵系统 (Chum)**：可制作碎饵撒到水中吸引鱼群
- 每个世界的鱼类种群分布是程序化生成的，不会背板
- 鱼有不同的活动区域和时间
- 钓鱼从被动等待变成主动寻找

## 🧪 液体系统 (Fluid System)

B42 引入了一个统一的液体管理框架。所有液体都有属性定义。

### 液体属性

| 属性     | 说明                                    |
| -------- | --------------------------------------- |
| 类别     | Beverage / Alcoholic / Fuel / Poisonous |
| 热量     | 每升卡路里                              |
| 酒精度   | 酒精百分比                              |
| 能量含量 | 燃料的能量值                            |

### 混合机制

- 可以把威士忌倒进橙汁 → 稀释鸡尾酒，属性按比例计算
- 漂白剂混进饮料 → 可定量的中毒效果（加一点生病，加一瓶致死）
- 任何容器可以装任何液体

### 应用场景

- 药水饮料调制
- 燃料混合
- Molotov 定制
- 汤/炖菜作为液体混合物
- MOD 可自定义液体类型注册

## 🎵 动态音乐

B42 的音乐系统从"播放背景音乐"升级为**动态适应**：

- 探索时 → 氛围音乐
- 紧张时（丧尸在附近）→ 紧张主题
- 战斗时 → 动作主题
- 过渡平滑，不会突然切换
- Zach Beever 原始原声+Formosa 合作多强度编曲

---

## 🗣️ 玩家语音

B42 首次引入**玩家角色语音**：

- 4 种男声 + 4 种女声可选
- 角色会咳嗽、打喷嚏、喘息、用力声
- 语音命令（"嘿！""嘘！"）可用于多人交流和引开丧尸
- 语音也是丧尸听觉系统的一部分——喊叫会引怪

## 🧟 丧尸系统变化

| 变化                            | 说明                                           |
| ------------------------------- | ---------------------------------------------- |
| **属性随机化**                  | 每只丧尸的耐久度、听力范围、速度都有随机浮动   |
| **新刷新热图**                  | 新生成系统带噪声叠加，以前安全的地方可能变危险 |
| **布娃娃物理**                  | 爆炸和撞击有真实物理效果                       |
| **丧尸砸栅栏不再给玩家 Stress** | B42.16 改动——栅栏被攻击不再触发玩家焦虑        |
| **Extinction Mode 白天跑尸**    | 灭绝模式新增白天冲刺丧尸                       |
| **持久警报**                    | 汽车警报不再能通过存读档消除                   |
