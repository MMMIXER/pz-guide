# B42 近战武器排名

基于 B42 新机制（肌肉疲劳、武器部件系统、锐利度、修理衰减）的全面排名。B41 老玩家注意——武器评价标准和 B41 **完全不同**了。

---

## ⚠️ B41 → B42 武器系统变化

在排名之前，理解这些新机制至关重要：

### 1. 肌肉疲劳

- 武器越重，持续挥舞时间越短
- 轻型武器的价值从"垃圾"变成"续航王"

### 2. 武器部件系统

- 刀刃武器：**刀头 + 手柄**分两条耐久
- 钝器更简单（无锐利度），但加固版（铁皮棒球棍）变重了

### 3. 锐利度

- 刀刃武器会**变钝**，伤害下降
- 需要用磨石/锉刀/砂轮打磨
- **武士刀不能磨**（2025-02-10 B42 补丁）——坏了就没了

### 4. 修理衰减

- 后续修理效果递减：50% → 25% → 10%
- 维护技能现在有更大意义（修得更值）

### 5. 可制作武器

- 锻造线可制作刀剑和加固棒球棍
- 终局有了可持续的武器来源

## 武器修理策略 (B42)

### 修理优先级

1. **撬棍等顶级耐久武器**：50% 时就修（修理衰减在高质量武器上损失最小）
2. **锻造武器**：用砂轮修——最安全，不会损伤武器
3. **不要用磨石/锉刀修锻造武器**——可能造成额外损伤
4. **武士刀**：用一次少一次，享受当下

### 修理工具

| 工具   | 适用     | 风险       |
| ------ | -------- | ---------- |
| 磨石   | 刀刃武器 | 有几率损伤 |
| 锉刀   | 刀刃武器 | 有几率损伤 |
| 砂轮   | 刀刃武器 | 最安全     |
| 胶带   | 砍刀等   | 标准修理   |
| 木工胶 | 木质武器 | 标准修理   |
