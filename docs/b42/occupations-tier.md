# B42 职业排名

基于 B42 当前版本的 meta，综合考虑**战斗力、经济性、B42 新机制适配度**做排名。重点标注 B42.16 的职业改动。

---

## B42 职业变化（B42.16 更新）

在排名之前，先看和 B41 相比的关键职业变化：

| 职业         | B41 状态             | B42 变化                                                     |
| ------------ | -------------------- | ------------------------------------------------------------ |
| **木匠**     | +3 木工              | 比以前值钱——拆解不给木工经验了，开局高木工让你直接造高级结构 |
| **建筑工**   | +3 短棍, +1 木工     | 钝器熟练现在**分开**了短棍和长棍，更精确                     |
| **护士**     | +2 急救, +1 轻手轻脚 | 新增**夜猫子特征内置**（值夜班理当如此）                     |
| **退伍兵**   | 从不恐慌             | 现在**还忽略不适感**，增益                                   |
| **所有职业** | 开局需看电视练级     | 职业起点技能更高，**不依赖早期电视冲级**                     |

### 新特征（B42.16）

| 特征           | 效果         | 点耗 |
| -------------- | ------------ | ---- |
| **能工巧匠**   | 增加维护技能 | 可选 |
| **射击爱好者** | 增加瞄准技能 | 可选 |

## B42 职业选择策略

### B42 的环境变化对职业的影响

```
肌肉疲劳 → 轻型武器开局更有吸引力（保安、汉堡店员工）
锻造系统 → 维护和木工价值大增（修理工、木匠）
荒野扩展 → 户外技能不再纯娱乐（公园管理员）
烹饪重做 → 厨师和汉堡店员工不再是凑数职业
光照重做 → 夜猫子从"还行"变"实用"
```

### 推荐开局路线

| 玩法风格     | 推荐职业              | 搭配                         |
| ------------ | --------------------- | ---------------------------- |
| **新手保险** | 修理工 + 正面特征     | 维护 +2 让武器活更久         |
| **战斗狂**   | 伐木工 + 速度特征     | 斧头专精 + 高体格 = 砍瓜切菜 |
| **枪械流**   | 退伍兵 + 射击爱好者   | 不恐慌不不适，站桩输出       |
| **潜行流**   | 大盗 + 轻量特征       | 接电发车 + 高机动            |
| **锻造流**   | 修理工 或 木匠        | 制作专注，维护/木工打底      |
| **荒野流**   | 公园管理员 + 户外特征 | 采集 + 诱捕 + 新狩猎系统     |

## 特征搭配建议

### B42 特别推荐的正向特征

| 特征              | 理由                                   |
| ----------------- | -------------------------------------- |
| **能工巧匠** (新) | 加维护——B42 最重要的技能之一           |
| **勇敢**          | 减少恐慌，退伍兵下位替代               |
| **强壮**          | 力量增加负重和伤害，肌肉疲劳下更有价值 |
| **运动健将**      | 体格直接影响武器挥舞可持续时间         |
| **猫眼**          | B42 光照重做后夜视能力价值飞升         |
| **灵巧**          | 物资转移加速，永远是好的               |
| **浅眠**          | 减少睡眠需求，更多时间干活             |

### B42 推荐负面特征

| 特征         | 给点 | B42 还值不值                                      |
| ------------ | ---- | ------------------------------------------------- |
| **吸烟者**   | +4   | ⚠️ B42 已削弱，不再是"免费点"。但烟草可以自己种了 |
| **口渴**     | +6   | 仍然安全，水源管理不变                            |
| **弱胃**     | +3   | 仍然安全（别吃变质食物就行）                      |
| **近视**     | +2   | 仍然可用，采集惩罚可接受                          |
| **缓慢愈合** | +6   | 安全，反正被咬了都是死                            |
| **薄皮**     | +8   | 高风险，被咬=死，但老玩家可控                     |
| **容易生病** | +4   | B42 天气更复杂，略增风险                          |
| **慢速阅读** | +2   | ⚠️ B42 技能书更重要了，**不推荐了**               |
