# B42 职业排名

基于 B42 当前版本的 meta，综合考虑**战斗力、经济性、B42 新机制适配度**做排名。重点标注 B42.16 的职业改动。

---

## B42 职业变化（B42.16 更新）

在排名之前，先看和 B41 相比的关键职业变化：

| 职业                             | B41 状态                     | B42 变化                                                       |
| -------------------------------- | ---------------------------- | -------------------------------------------------------------- |
| **木匠 (Carpenter)**             | +3 Carpentry                 | 比以前值钱——拆解不给木工 XP 了，开局高木工能让你直接造高级结构 |
| **建筑工 (Construction Worker)** | +3 Short Blunt, +1 Carpentry | 钝器熟练现在**分开**了 Short Blunt 和 Long Blunt，更精确       |
| **护士 (Nurse)**                 | +2 First Aid, +1 Lightfooted | 新增 **Night Owl 特征内置**（值夜班理当如此）                  |
| **老兵 (Veteran)**               | Desensitized (免疫恐慌)      | Desensitized 现在**还忽略 Discomfort**（不适感），Buff         |
| **所有职业**                     | 开局需 TV 练级               | 职业起点技能更高，**不依赖早期 TV 冲级**                       |

### 新特征（B42.16）

| 特征               | 效果                  | 点耗 |
| ------------------ | --------------------- | ---- |
| **Tinkerer**       | 增加 Maintenance 技能 | 可选 |
| **Target Shooter** | 增加 Aiming 技能      | 可选 |

## B42 职业选择策略

### B42 的环境变化对职业的影响

```
肌肉疲劳 → 轻型武器开局更有吸引力（Security Guard, Burger Flipper）
锻造系统 → Maintenance 和 Carpentry 价值大增（Repairman, Carpenter）
荒野扩展 → 户外技能不再纯娱乐（Park Ranger）
烹饪重做 → 厨师和汉堡工不再是凑数职业
光照重做 → Night Owl 从"还行"变"实用"
```

### 推荐开局路线

| 玩法风格     | 推荐职业                 | 搭配                                 |
| ------------ | ------------------------ | ------------------------------------ |
| **新手保险** | Repairman + 正面特征     | Maintenance +2 让武器活更久          |
| **战斗狂**   | Lumberjack + 速度特征    | Axe Man + 高体能 = 砍瓜切菜          |
| **枪械流**   | Veteran + Target Shooter | 不恐慌不不适，站桩输出               |
| **潜行流**   | Burglar + 轻量特征       | Hotwire + 高机动                     |
| **锻造流**   | Repairman 或 Carpenter   | 制作专注，Maintenance/Carpentry 打底 |
| **荒野流**   | Park Ranger + 户外特征   | Foraging + Trapping + 新狩猎系统     |

## 特征搭配建议

### B42 特别推荐的正向特征

| 特征              | 理由                                   |
| ----------------- | -------------------------------------- |
| **Tinkerer** (新) | 加 Maintenance——B42 最重要的技能之一   |
| **Brave**         | 减少恐慌，老兵下位替代                 |
| **Stout/Strong**  | 力量增加负重和伤害，肌肉疲劳下更有价值 |
| **Athletic/Fit**  | 体能直接影响武器挥舞可持续时间         |
| **Cat's Eyes**    | B42 光照重做后夜视能力价值飞升         |
| **Dextrous**      | 物资转移加速，永远是好的               |
| **Wakeful**       | 减少睡眠需求，更多时间干活             |

### B42 推荐负面特征

| 特征                 | 给点 | B42 还值不值                                      |
| -------------------- | ---- | ------------------------------------------------- |
| **Smoker**           | +4   | ⚠️ B42 已削弱，不再是"免费点"。但烟草可以自己种了 |
| **High Thirst**      | +6   | 仍然安全，水源管理不变                            |
| **Weak Stomach**     | +3   | 仍然安全（别吃变质食物就行）                      |
| **Short Sighted**    | +2   | 仍然可用，觅食惩罚可接受                          |
| **Slow Healer**      | +6   | 安全，反正被咬了都是死                            |
| **Thin-skinned**     | +8   | 高风险，被咬=死，但老玩家可控                     |
| **Prone to Illness** | +4   | B42 天气更复杂，略增风险                          |
| **Slow Reader**      | +2   | ⚠️ B42 技能书更重要了，不推荐了                   |
