# 新地图与探索

B42 的地图在 B41 基础上做了**垂直扩展**（向上和向下）和**水平扩展**（向西和向外）。对 B41 老玩家来说，熟悉的城市仍在，但多了大量新区域。

---

## 新城镇与区域

### 三大新城镇

B42 在俄亥俄河沿岸向西扩展了地图，新增 3 个新城镇：

| 城镇                     | 特色                       | 大小   |
| ------------------------ | -------------------------- | ------ |
| **新城镇 A**（西部沿河） | 沿河定居点，渔资源丰富     | 中小型 |
| **新城镇 B**（西部内陆） | 农业区，农场多             | 中小型 |
| **废弃西部小镇**         | 仿古旅游景点风格，独特氛围 | 小型   |

> 确切城镇名称待官方和社区进一步确认，以上基于更新日志描述。

## 🏙️ 摩天大楼（32 层极限）

B42 把建筑高度上限从 7 层提升到 **32 层**。路易斯维尔现在有了真正意义上的摩天大楼。

### 探索策略

- 每层都是未知——你永远不知道下一层有什么样的办公室、会议室、走廊
- 楼道和楼梯间最危险——狭窄空间遭遇丧尸没有退路
- **顶楼基地**：安全性极高（丧尸不太可能爬 30 层），但每次外出回来都要爬很久
- 用**逃生绳（Sheet Rope）**从窗户快速下楼，但要确保绳子在

::: danger 高楼风险
32 层的楼梯间如果有丧尸群，你无路可逃。进去之前确保有退路——逃生绳、足够体力、备用武器。
:::

## 🏚️ 地下室与地堡

B42 世界首次向**地下**延伸。部分房屋会随机生成隐藏地下室。

### 地下室类型

| 类型                           | 内容                               |
| ------------------------------ | ---------------------------------- |
| **核避难所 (Fallout Shelter)** | 物资齐全的地下掩体，可能含稀有物资 |
| **恐慌室 (Panic Room)**        | 专门的安全房间，加固门+应急物资    |
| **储物间**                     | 普通地下储藏室，可能有食物和工具   |
| **酒窖**                       | 葡萄酒和其他酒类储存               |
| **"特殊"地下室**               | 古怪/恐怖主题的隐藏房间            |

### 进入方式

- 通过壁橱、地板上的**暗门 (Trap Door)** 进入
- 不一定每栋房子都有——可以在沙盒设置中调整出现频率
- 地下室窗口极少——完全的黑暗环境

::: danger 地下室生存法则
地下室没有窗户、漆黑一片、只有一个出入口。进去前确保：

1. 手电筒 + 备用电池
2. 清理了楼上所有丧尸（免得被堵死出口）
3. 随时准备丢闪光弹或火把照明
   :::

## 🌲 无限荒野

地图边界外的"隐形墙"被**程序化生成的荒野**替代了。

- 地图边界外生成无限的森林、河流、丘陵地形
- 支持真正的**原始生存**玩法——远离文明，完全自给自足
- 沙盒选项中可选择**纯荒野世界**（完全没有城镇和建筑）
- 对于游牧/猎人角色来说，世界现在"无限大"

---

## 📍 出生点变更

::: warning Echo Creek 不再作为出生点
B42.16 开始，Echo Creek 不再是可选的出生地点。它仍然存在，可以作为目的地前往，但不能在这里出生。
:::

B41 的出生城镇（Rosewood、Riverside、Muldraugh、West Point）继续保留为出生选项。

---

## 🗺️ 对 B41 玩家的导航建议

1. **旧地图仍然有用**——熟悉的主要道路和城镇布局没变
2. **向西探索新区域**——俄亥俄河现在是西部新边界
3. **高楼是新的终极目标**——后期探索路易斯维尔的摩天楼
4. **地下室刷在旧房子里**——不要忽略你"熟悉"的建筑物，检查壁橱！
