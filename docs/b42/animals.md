# 畜牧与狩猎

B42 首次引入了**活物**——Knox County 不再是只有你一个活人了。动物系统包含**驯养**和**狩猎**两条独立的玩法线，是 B42 "自给自足"理念的核心支柱。

::: tip B41 玩家注意
动物是 B42 的**完全新系统**，B41 中没有任何对应的内容。这也被称为"Project Zomboid 的第一个 NPC 系统"。
:::

## 驯养系统 (Animal Husbandry)

### 如何获取家畜

1. 找到农场或田野中的动物
2. 用绳子或诱饵将其引导至你的基地
3. 搭建围栏/圈栏（木工或石工制作）
4. 使用拖车运输大型动物

### 日常管理

| 任务     | 频率   | 说明                             |
| -------- | ------ | -------------------------------- |
| 喂食     | 每日   | 不同动物需要不同饲料，猪可吃残羹 |
| 收集产物 | 每日   | 鸡蛋、牛奶每日可收；羊毛定期收割 |
| 清洁围栏 | 定期   | 防止疾病                         |
| 防狐狸   | 持续性 | 狐狸会偷幼崽，需加固围栏或设陷阱 |

### 产品链

```
家畜 ──→ 肉（直接食用或烟熏保存）
    ├── 皮革 ──→ 护甲、腰带、枪套
    ├── 骨头 ──→ 针、鱼钩、鱼陷阱、骨粉肥料
    ├── 羊毛 ──→ 纺线 ──→ 冬衣
    ├── 粪便 ──→ 作物肥料（闭合农耕循环）
    ├── 牛奶 ──→ 饮用或制奶酪（需开发中功能）
    └── 鸡蛋 ──→ 食用或烹饪（高效烹饪 XP）
```

## 狩猎系统 (Hunting)

### 追踪技能 (Tracking)

B42 新增技能——通过追踪脚印、粪便、断枝来定位猎物：

- 鹿沿固定迁徙路线移动，找到路线就能反复狩猎
- 枪声和雷声会惊吓动物，暂时压制其活动
- 弓是理想的无声狩猎武器（弓技能推迟开发中）
- 响亮的枪声可以用来故意驱赶动物离开某个区域

### 狩猎技巧

::: tip 追踪技巧

- 雨后泥土上更容易看到新鲜足迹
- 顺着粪便的"新鲜度"判断猎物离你有多远
- 在林区边缘比密林深处更容易发现鹿
  :::

## ⚠️ 重要机制

### 丧尸无视动物

好消息：丧尸不会攻击你的牲畜。坏消息：动物也不会帮你引开丧尸。

### 但动物怕噪音

- 枪声 → 动物逃跑，暂时不活动
- 雷暴 → 同上
- 丧尸砸门声 → 不会吓到动物

### 动物不会生小崽（当前版本）

繁殖机制尚未完全实装——但幼崽模型（小鹿、羊羔）已经在游戏中出现，暗示未来会有。目前需要通过野外不断寻找新动物来补充。

## 推荐开局路线

1. **早期**：养鸡——最省心的动物，每日鸡蛋提供稳定食物和烹饪 XP
2. **中期**：加养猪——吃残羹不费饲料，提供大量肉和皮
3. **后期**：养牛/羊——终极食物/资源自给
4. **与农耕联动**：动物粪便当肥料，种出来的次品喂猪，形成闭环
