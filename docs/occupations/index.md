# 📋 职业与特性

Project Zomboid B41 有 **21 个职业**（Occupation）和 **88 个特性**（Traits）。角色创建时职业决定初始技能等级和经验倍率，特性影响角色强弱，正负面特性点数平衡。

## 经验倍率说明

- 125% 倍率 = 获得经验时额外 +25%
- 100% 倍率 = 标准经验获取
- 无倍率 = 无加成

::: tip 老兵职业亮点
退伍兵 (Veteran) 独有特性「Desensitized」——永远不会恐慌，意味着精准度不受僵尸群数量影响，是枪械流派的首选。
:::
