B42 职业排名 ​

基于 B42 当前版本的 meta，综合考虑战斗力、经济性、B42 新机制适配度做排名。重点标注 B42.16 的职业改动。

B42 职业变化（B42.16 更新） ​

在排名之前，先看和 B41 相比的关键职业变化：

职业B41 状态B42 变化
木匠+3 木工比以前值钱——拆解不给木工经验了，开局高木工让你直接造高级结构
建筑工+3 短棍, +1 木工钝器熟练现在分开了短棍和长棍，更精确
护士+2 急救, +1 轻手轻脚新增夜猫子特征内置（值夜班理当如此）
退伍兵从不恐慌现在还忽略不适感，增益
所有职业开局需看电视练级职业起点技能更高，不依赖早期电视冲级

新特征（B42.16） ​

特征效果点耗
能工巧匠增加维护技能可选
射击爱好者增加瞄准技能可选

排名总览 ​

S 档 — 版本答案 ​

职业费用核心优势B42 适配
🥇 伐木工0斧头专精（+25% 斧头挥速+砍树速度）, +2 斧头, +1 力量斧类武器始终顶级，0 成本福利之王
🥈 退伍兵-8从不恐慌（永不恐慌 + 现在也忽略不适感）, +2 瞄准, +2 装弹B42 增益：不适感免疫让重甲角色受益
🥉 大盗-6可以直接接电发动车辆, +2 灵活/+2 潜行/+2 轻手轻脚接电发车仍是游戏中最稀缺的早期能力，灵活对战斗机动性极关键

A 档 — 强力选择 ​

职业费用核心优势B42 适配
消防员0+1 斧头/+1 体格/+1 冲刺/+1 力量全面且 0 成本，开局就是强化版平民
修理工-4+2 维护, +1 木工, +1 短棍维护在 B42 极度重要——武器寿命+自制物品耐久
木匠+2+3 木工拆解不给木工经验后，开局高木工价值飙升
建筑工-2+3 短棍, +1 木工B42.16 后短棍/长棍技能分开，定位更清晰
机械师-4业余机械师, +3 机械, +1 短棍车辆仍是生存核心，专业机械师价值不减

B 档 — 可选 ​

职业费用核心优势说明
警察-4+3 瞄准, +1 灵活, +2 装弹枪械角色，但枪声引怪是硬伤。灵活价值高
保安-2夜猫子, +1 轻手轻脚, +2 冲刺便宜好用，夜猫子适合夜间作业
公园管理员-4+1 斧头, +1 木工, +2 采集, +2 诱捕B42 荒野生存 + 狩猎系统让户外职业更实用
健身教练-6营养学家, +3 体格, +2 冲刺体格对肌肉疲劳系统有直接帮助
厨师-4厨师, +3 烹饪, +1 维护, +1 短刀B42 烹饪系统重做 + 食物保存 = 厨师价值上升
汉堡店员工+2厨师, +2 烹饪, +1 维护, +1 短刀最便宜获得维护的方式（反赚 2 点），性价比之王
电工-4+3 电工发电机能力，但杂志也能解决
工程师-4+1 木工, +1 电工配方独特（炸弹/陷阱），娱乐性大于实用

C 档 — 不推荐（除非角色扮演） ​

职业费用原因
医生+2急救是游戏中最没用的技能——被咬了 100% 死，小伤随便处理
护士+2急救 + 轻手轻脚 + 内置夜猫子。比医生好一点但仍然一般
农民+2农耕是最容易练的技能之一，不值得用职业点
渔夫-2钓鱼重做后更互动，但技能本身容易练，不必占职业位
金属工-6锻造线需要大量前置投入，开局选金属工不如后期转职

特殊 — 自定义 ​

职业费用说明
失业+88 点自由分配，配合版本最强负面特征可凑出暴力开局

B42 职业选择策略 ​

B42 的环境变化对职业的影响 ​

肌肉疲劳 → 轻型武器开局更有吸引力（保安、汉堡店员工）
锻造系统 → 维护和木工价值大增（修理工、木匠）
荒野扩展 → 户外技能不再纯娱乐（公园管理员）
烹饪重做 → 厨师和汉堡店员工不再是凑数职业
光照重做 → 夜猫子从"还行"变"实用"

推荐开局路线 ​

玩法风格推荐职业搭配
新手保险修理工 + 正面特征维护 +2 让武器活更久
战斗狂伐木工 + 速度特征斧头专精 + 高体格 = 砍瓜切菜
枪械流退伍兵 + 射击爱好者不恐慌不不适，站桩输出
潜行流大盗 + 轻量特征接电发车 + 高机动
锻造流修理工 或 木匠制作专注，维护/木工打底
荒野流公园管理员 + 户外特征采集 + 诱捕 + 新狩猎系统

特征搭配建议 ​

B42 特别推荐的正向特征 ​

特征理由
能工巧匠 (新)加维护——B42 最重要的技能之一
勇敢减少恐慌，退伍兵下位替代
强壮力量增加负重和伤害，肌肉疲劳下更有价值
运动健将体格直接影响武器挥舞可持续时间
猫眼B42 光照重做后夜视能力价值飞升
灵巧物资转移加速，永远是好的
浅眠减少睡眠需求，更多时间干活

B42 推荐负面特征 ​

特征给点B42 还值不值
吸烟者+4⚠️ B42 已削弱，不再是"免费点"。但烟草可以自己种了
口渴+6仍然安全，水源管理不变
弱胃+3仍然安全（别吃变质食物就行）
近视+2仍然可用，采集惩罚可接受
缓慢愈合+6安全，反正被咬了都是死
薄皮+8高风险，被咬=死，但老玩家可控
容易生病+4B42 天气更复杂，略增风险
慢速阅读+2⚠️ B42 技能书更重要了，不推荐了
