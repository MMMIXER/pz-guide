农业 2.0 ​

B42 的农业系统从"挖坑撒种等收"变成了真正需要思考和规划的农耕模拟。对 B41 老玩家来说，这是最大的玩法改变之一。

B41 经验不再适用

B41 的"随便种种就能活"不适用了。B42 种错过季节的作物会颗粒无收。

⚠️ B41 → B42 核心变化 ​

变化B41B42
季节系统无，全年可种每种作物有特定种植季节
室内种植可反季节室内种植也会失败（室内绿植除外）
生长时间固定天数受温度、日照、降雨综合影响
种子品种7 种作物50+ 种子品种
害虫无蛞蝓、蜗牛攻击作物
杂草无需定期除草
操作方式右键菜单"星露谷化"——锄头战斗姿态挖沟，种子在手按交互键播种

季节系统 ​

每种作物只有在正确的季节才能生长。种错季节 = 白种。

按季节划分 ​

季节推荐种植
春季 🌱豌豆、大蒜、亚麻、大麦、啤酒花、烟草、大部分香草
夏季 ☀️玉米、番茄、向日葵、辣椒、大部分蔬菜
秋季 🍂黑麦、土豆、洋葱、胡萝卜、甜菜
冬季 ❄️几乎无法户外种植——依赖储存食物过冬

冬季生存策略 ​

  • 冬季成为真正的食物短缺威胁
  • 必须在春夏秋三季积累足够的腌制/烟熏/干制食物
  • 制陶（储存罐）和烹饪（食物保存）技能在冬天的价值飙升

关键联动 ​

  • 土豆/洋葱/大蒜 → 本身就能当种子用（不用专门找种子包）
  • 烟草 → 有吸烟者特征的玩家可以自种香烟，不再完全依赖搜刮
  • 香草 → 可反复收割，可能驱虫或有药用效果
  • 大麦+啤酒花 → 酿酒联动（酿酒功能上线后）
  • 亚麻+大麻 → 裁缝/制绳，闭合衣物生产循环

害虫与疾病 ​

威胁一览 ​

威胁表现对策
🐌 蛞蝓/蜗牛啃食作物，降低产量① 商品杀虫剂 ② 种迷迭香在旁边 ③ 散养鸡吃虫
🌿 杂草与作物争夺养分定期手动除草
🦠 病害霉菌、枯萎等及时移除病株防止扩散

生态闭环 ​

鸡吃害虫 → 鸡产蛋/粪 → 粪肥田 → 作物健壮 → 次品作物喂猪 → 猪肉

操作改善 ​

B42 的农耕操作被社区戏称为"星露谷物语化"：

  1. 装备锄头 → 进入战斗姿态 → 即可挖掘犁沟（不再是右键菜单）
  2. 种子拿在手上 → 对准犁沟按交互键 → 播种
  3. 犁沟和作物生长阶段有可视化反馈，比 B41 直观得多

新手建议

第一季先少种几排练手，掌握季节+害虫管理后再大规槿扩产。错过一季就是几个月没吃的。

B41 作物在 B42 的状态 ​

B41 的 7 种基础作物（土豆、胡萝卜、番茄、卷心菜、西兰花、草莓、萝卜）仍然存在，但：

  • 每种都有了特定的种植季节
  • 生长速度受环境因素影响，不再是固定天数
  • 疾病风险比 B41 高
