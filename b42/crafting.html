锻造与制作系统 ​

B42 的核心灵魂——制作系统被彻底重写。新增 6 个制作技能，技能之间互相依赖，形成复杂的生产链。老玩家最需要适应的变化：拆家具不给木工 XP 了，技能书现在解锁配方而不只是 XP 倍率。

⚠️ B41 → B42 关键变化 ​

拆解不再给木工 XP

B41 靠拆双人床练木工的时代结束了。B42 必须通过建造物品来提升木工等级。早期最佳 XP 来源：造木杆（1 木板 + 1 钉子）。

技能书解锁配方

技能书在 B42 不再是"读了赚更多 XP"，而是你不读就看不到配方。看到技能书就拿起，尤其是你打算深造的技能线。

技能互相依赖

你不能只练一个技能到满级。做金属工具需要陶艺做坩埚，陶艺需要木工做陶轮，石器需要锻造做工具…每一条线都依赖其他线的最低等级。

六大新技能 ​

技能核心功能关键工具入门门槛
锻造 (Blacksmithing)冶炼金属、锻打刀剑/工具/钉子原始熔炉 → 锻炉 → 铁砧中等（需要陶艺+石工配合）
制陶 (Pottery)制作坩埚、储水罐、炊具、砖块陶轮 + 窑炉低（河边挖粘土即可开始）
打制石器 (Knapping)制作石刀、石斧头、箭头、燧石片石头或锤子 + 燧石结核极低（捡石头就行）
雕刻 (Carving)削制武器手柄/柄杆、木碗、骨针/鱼钩任意小刀（含石刀）极低（树枝+小刀）
石工 (Masonry)石基/石墙、砖炉、防御石墙、水泥石工凿 + 抹刀中等（需 Knapping 做凿子）
玻璃工艺 (Glassmaking)玻璃窗、储存罐、实验室器皿粘土塑形工具 + 熔炉高（工具稀有）

锻造冲级技巧 ​

  • Lv4-5 期间：批量制作带扣 (Buckle)——每只需 1 块钢，但制作钢条本身给大量 XP
  • 木炭生产：篝火法（需铲子）或炭桶法（任意金属桶，不占地）

旧技能的变化 ​

木工 (Carpentry) ​

  • ❌ 拆家具不给 XP
  • ✅ 早期造木杆（1 木板+1 钉子）练级
  • 支持陶艺台、陶轮等新制作站

维护 (Maintenance) ​

  • 🔼 重要性大幅提升——直接影响自制物品的寿命
  • 现在通过战斗使用和修理物品正常获得 XP（修复了之前 Crowbar 不给 XP 的 bug）
  • 磨练石 (Whetstone) 可打磨刀刃武器

烹饪 (Cooking) ​

  • 完全重做：新增烟熏、盐腌、干燥等保存方式
  • 收集鸡蛋 → 烤箱烹饪 → 收获熟蛋（高效 XP）
  • 屠宰动物时注意收集骨头（给屠宰 XP）

裁缝 (Tailoring) ​

  • 不能撕衣服获得线了——必须从破布中回收或搜刮
  • 到达 Lv1 最快方法：把牛仔裤改短裤，或连衣裙改短裙
  • Lv1 后：从破布回收线 → 反复贴/拆破布补丁练级

电工 (Electrical) ​

  • 基本不变：拆电子设备练级
  • 发电机相关不变

技工 (Mechanics) ​

  • 杂志更重要了，每种车型（标准/运动/重型）需要各自的杂志
  • 练级方法不变："忒修斯之船"拆换零件

焊接 (Welding) ​

  • 丙烷焊枪、丙烷罐、焊工面罩都是搜刮品，不能制作
  • 拆废车残骸获取金属练级

制作协同链 ​

食物自给流水线 ​

木工 → 农耕设施 → 觅食（种子）→ 耕种 → 烹饪（保存）→ 陶艺（储存）

武器自给流水线 ​

打制石器（基础工具/零件）→ 雕刻（手柄/柄杆）→ 锻造（刀刃/加固件）→ 维护（延长寿命）

建造流水线 ​

木工（基础结构）→ 石工（石基/石墙/窑炉）→ 锻造（金属加固）

B42 制作系统的设计目标 ​

B42 制作系统为未来打基础：

  1. 丰富的终局——不只是"囤物资然后无聊"
  2. 无限服务器——不需要刷新物资，玩家可从原料造一切
  3. 社区协作——不同职业促进交易与互动（为 B43+ NPC 做准备）
  4. 完全荒野科技树——假设没有文明废墟，也能从零造出所有物品
